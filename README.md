# 🐷 Cofrinho — Finanças da Casa

App web simples, visual, com lembretes e gamificação para Marina & Higor gerirem as finanças da casa.

**App ao vivo:** https://marinasdearaujo.github.io/cofrinho/

## O que faz
- **Lançamentos rápidos** de entradas e saídas, por categoria (mercado, moradia, pet, casa nova...).
- **Contas a pagar** com vencimento, aviso de "vence hoje / atrasada", contas que repetem todo mês e botão *Pagar* (vira gasto automaticamente).
- **Orçamento do mês** com barra de progresso e alerta quando passa de 80%.
- **Metas** (reserva, casa nova Maringá...) com barra de progresso, prazo e **recompensa** ao bater.
- **Gamificação completa**: XP, níveis, sequência de dias (🔥 streak), 12 conquistas, desafio do mês (você + Higor) e confete ao desbloquear.
- **Lembretes** via notificação do navegador quando uma conta está chegando.
- **Importar extrato (CSV)** do banco e **backup/restauração** dos dados.
- **Pra onde foi seu dinheiro**: gráfico de gastos por categoria.

## Privacidade
Tudo fica **só no seu aparelho** (localStorage). Nada vai pra servidor, não precisa login. Faça *Backup* de vez em quando (aba Você).

## Integração bancária (fase 2)
Hoje é manual + import de CSV. Open Finance (conexão automática com banco) exige serviço pago tipo Pluggy/Belvo — fica para uma próxima fase, já que a base está pronta pra plugar.

## Como usar
Abra o link acima no celular e use **"Adicionar à tela de início"** para virar um app de verdade. Funciona offline.
